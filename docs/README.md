# MileWage documentation

- [`help/`](help/README.md): help for drivers, in plain words. The same pages are in the web app, under Help, for the version your server runs.
- [`development.md`](development.md): for developers. The parts, how to run and check the code, the folders, how a release is cut.
- [`adr/`](adr/README.md): architecture decisions from 2026-11-09 on, for developers. The help pages stay for drivers.
- [`story.md`](story.md): the story behind MileWage, from a spreadsheet to this.

To install or upgrade the server, see [`infra/docs/install.md`](../infra/docs/install.md) and [`infra/docs/upgrade.md`](../infra/docs/upgrade.md). Setting it up with an AI coding agent? Give it [`infra/docs/agent-setup.md`](../infra/docs/agent-setup.md).

# Architecture decision records

This folder is for developers. The guides for drivers are in [`docs/help/`](../help/README.md).

Decisions made before 2026-11-09 are indexed in [`DECISIONS.md`](../../DECISIONS.md) at the repository root. They are not copied here.

From 2026-11-09 on, each new architecture decision is recorded here as an ADR, in the format of [`.agents/skills/domain-modeling/ADR-FORMAT.md`](../../.agents/skills/domain-modeling/ADR-FORMAT.md): one file per decision, numbered in order (`0001-slug.md`, `0002-slug.md` and so on). Write one only when the decision is hard to reverse, surprising without context and the result of a real trade-off.

`DECISIONS.md` stays the human index: each new ADR gets a one-line row there that points to its file.

The words of the domain are in [`GLOSSARY.md`](../../GLOSSARY.md).
